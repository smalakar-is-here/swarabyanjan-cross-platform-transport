# Data

This public repository does **not** redistribute raw third-party datasets or frozen derived artifacts that contain third-party text/row-level source bytes when public redistribution permission is unresolved.

- `access/` documents source identities, acquisition routes, licensing/redistribution uncertainty, and the public-safety boundary.
- `derived/` contains only retained non-text-bearing derived interfaces whose public inclusion does not copy the excluded literal third-party text caches identified by the final safety audit.
- `../provenance/external_restricted/` records the exact filenames, expected paths, sizes and SHA-256 values of excluded artifacts.

Aggregate scientific result tables remain under `../results/`.

A fresh clone is therefore not a self-contained source-data distribution and must not be described as fully reproducible from scratch without authorised external inputs.
