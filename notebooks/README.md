# Canonical Scientific Notebooks

This directory contains exactly the nine canonical scientific source notebooks, Stage01–Stage09.

It intentionally excludes:

- Stage10 release engineering;
- release/anonymized notebook copies;
- legacy/repair variants;
- Rule A / Rule B sensitivity notebooks.

See `../docs/CANONICAL_NOTEBOOK_MAP.md`.

## Public-safe execution note

Some notebooks refer to frozen artifacts intentionally excluded from the public package. Restore only authorised copies at the exact paths/hashes listed in `../provenance/external_restricted/` before execution. A fresh public clone is not a self-contained data distribution.
